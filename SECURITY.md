# Security Policy

## Supported Versions

Only the latest tagged release receives security fixes. There is no
long-term support branch; see [AGENTS.md](AGENTS.md) for how releases work.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead,
email <sergey24rybak@gmail.com> with:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Which part of the stack is affected (backend, frontend, MCP server, or the
  OpenAI-compatible API)

We'll acknowledge your report and let you know whether it's accepted as a
valid issue. Once a fix is available, we'll coordinate on disclosure timing
with you before any public write-up.
