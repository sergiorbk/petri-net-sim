# Petri Net Sim 1.2.0

Export network images and session training bundles, with shared modeling guidance and reliable PNML simulation round trips.

## Changes

- Download PNG network images and training ZIPs through the interface, built-in chat and MCP.
- Bundles include PNML, supplied context, available real conversation and tool records, images, geometry, verification observations and SHA-256 hashes. Missing evidence and review status remain explicit.
- Chat exports use the existing signed download channel. Credentials are redacted from exported metadata.
- Shared Petri modeling skills include guidance for reconstructing networks from photos and diagrams through a vision-capable client.
- Preserve semantic place tags through flat and composed PNML save/import, including throughput counters.
- Fix PostgreSQL checkpoint initialization on Windows through the supported selector event-loop factory.
- Keep arrowheads visible on vertical transition arcs in exported images.

Builds now install shared skills from a pinned GitHub Release wheel with SHA-256 verification. A plain Git clone is sufficient.

## Distribution

Publishing this release builds ghcr.io/sergiorbk/petri-net-sim-local:v1.2.0 and updates latest. This image targets linux/amd64 and uses single-user mode. It is intended for local use.

The repository's release publication workflow can also start deployment when deployment secrets are configured.
